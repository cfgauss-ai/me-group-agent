Começar

No ar em 4 comandos

Um assistente pergunta o nome do bot, o canal e (se quiser) a chave de IA, e escreve a configuração por você. O QR do WhatsApp aparece no próprio terminal.

⚠️ Use um número de WhatsApp secundário. A conexão por QR usa a biblioteca não-oficial Baileys — contraria os Termos da Meta e pode banir o número. O Telegram usa a API oficial e não tem esse risco. 
# clone o template (grátis)
$ git clone github.com/cfgauss-ai/me-group-agent
$ cd me-group-agent

# instale e configure (assistente)
$ npm install && npm run setup

# suba — o QR aparece aqui
$ npm start
✓ whatsapp conectado · telegram conectado
Dúvidas

Perguntas rápidas

É grátis mesmo? Qual a pegadinha?
Sem pegadinha. A ME é open-source (MIT) e roda na sua máquina — não tem plano, cartão nem limite de grupos. O único custo possível é se você ligar a IA: aí você usa sua própria chave (OpenRouter) e paga só o que consumir. Dá pra usar tudo sem IA e ficar 100% grátis.
Preciso saber programar?
Pra colocar no ar, você roda três comandos e um assistente configura o resto. Mexer no código é opcional — a ME funciona como vem.
Funciona no Telegram também?
Sim. A mesma ME atende WhatsApp e Telegram ao mesmo tempo, em vários grupos.
Meu número pode ser banido?
No WhatsApp a conexão é não-oficial (biblioteca Baileys), então use um número secundário — contraria os Termos da Meta e há risco de banimento. No Telegram é a API oficial, sem esse risco.
Dá pra personalizar?
Tudo: nome, personalidade, regras de moderação, base de conhecimento e horários saem de um arquivo de configuração que é seu.
