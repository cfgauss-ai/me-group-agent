Por que confiar

Três coisas que não são promessa — são código

Está nos testes e na varredura de segredos do CI, não num texto de marketing.

Nada de ninguém vaza

O template nasce neutro: só exemplos fictícios e placeholders. O CI bloqueia o build se achar qualquer segredo.

Totalmente seu

Nome, personalidade, regras, base de conhecimento e horários — tudo vem de um arquivo que você controla.

Simples de verdade

Clonar, npm run setup, npm start. Roda em qualquer máquina com Node — ou via Docker.

Começar

Do zero ao bot no ar

Quatro comandos. O assistente pergunta o nome do bot, o canal e a chave de IA (se quiser) e escreve a config por você. O QR do WhatsApp aparece no próprio terminal.

⚠️ Use um número de WhatsApp secundário. A conexão por QR usa a biblioteca não-oficial Baileys — contraria os Termos da Meta e pode banir o número. O Telegram usa a API oficial e não tem esse risco. 
# clone o template
$ git clone github.com/cfgauss-ai/me-group-agent
$ cd me-group-agent

# instale e configure (assistente)
$ npm install && npm run setup

# suba — o QR aparece aqui
$ npm start
✓ whatsapp conectado · telegram conectado
