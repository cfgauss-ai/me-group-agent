Um agente de IA dentro do seu grupo, no ar em minutos.

A ME recebe novos membros, modera spam, responde dúvidas com IA e posta conteúdo na hora certa — no seu grupo de WhatsApp e Telegram. Você clona, configura em um arquivo e roda. De graça.

O que ela faz

Tudo o que um grupo precisa, em um bot só

Cada função liga ou desliga no seu config.yaml. Nada é obrigatório.

👋

Boas-vindas

Mensagem automática e regras do grupo para cada novo membro — uma vez só, com o nome dele.

🛡️

Moderação

Anti-spam por palavra, links e flood. Avisa, apaga ou remove — você escolhe por regra.

🤖

Respostas com IA

Responde dúvidas a partir da sua base de conhecimento, via OpenRouter. Com trava de custo por grupo.

📅

Conteúdo agendado

Lembretes e posts em horários definidos, mais um resumo do dia do grupo.

💬

Dois canais

WhatsApp (via QR Code) e Telegram ao mesmo tempo, na mesma instância, em vários grupos.

⚡

Fácil de configurar

Um assistente pergunta o essencial e escreve a config pra você. QR aparece no terminal.

Por que confiar

Três compromissos do projeto

Não é promessa de marketing — está no código e nos testes.

01

Nenhum dado de terceiros

O template nasce neutro: só exemplos fictícios e placeholders. Varredura de segredos no CI bloqueia qualquer vazamento.

02

Totalmente seu

Nome, persona, regras, base de conhecimento, horários — tudo vem de um arquivo de configuração que você controla.

03

Simples de verdade

Clonar, npm run setup, npm start. Roda em qualquer máquina com Node, ou via Docker.

Começar

Do zero ao bot rodando

Quatro comandos. O assistente cuida do resto.

# 1. clone o template
$ git clone https://github.com/cfgauss-ai/me-group-agent
$ cd me-group-agent

# 2. instale e configure (assistente interativo)
$ npm install
$ npm run setup

# 3. suba o bot — o QR do WhatsApp aparece aqui
$ npm start
✓ canal whatsapp conectado · canal telegram conectado
⚠️ Use um número de WhatsApp secundário. A conexão por QR Code usa uma biblioteca não-oficial (Baileys), o que contraria os Termos da Meta e pode levar ao banimento do número. Para produção dentro das regras, migre para a API oficial. O Telegram usa a API oficial (BotFather) e não tem esse risco.
